# 第四阶段：接线

按程序 `config.h` 的定义接。先只接线、**先不要给 L298N 接电池**。
电源三个螺丝看板子丝印，不要凭上下顺序猜。

## 你照片里的绿框是什么

那一排一共 **6 根针**：

```
（靠近 3 个螺丝电源座、照片里绿框靠上、带着黑帽）
  ENA    ← 现在插着跳线帽，要拔掉，接到 ESP D5
  IN1    ← 空针，接到 ESP D1
  IN2    ← 空针，接到 ESP D2
  IN3    ← 空针，接到 ESP D7
  IN4    ← 空针，接到 ESP D8
  ENB    ← 现在插着跳线帽，要拔掉，接到 ESP D6
（靠近 2 个螺丝电机座、照片里绿框靠下、带着黑帽）
```

翻到 L298N **背面**，针脚旁边一般印着 `ENA IN1 IN2 IN3 IN4 ENB`。以丝印为准。

两端的黑色帽子 = 跳线，把 ENA/ENB 短接到 5V，电机永远满速。
我们要用网页调速，**这两个帽子都拔掉**，再把针接到 ESP。

中间四个空针只决定转向，不接速度：

| 针 | 作用 |
|----|------|
| IN1 + IN2 | 左电机（OUT1/OUT2）正转 / 反转 |
| IN3 + IN4 | 右电机（OUT3/OUT4）正转 / 反转 |

- IN1=高、IN2=低 → 左电机正转
- IN1=低、IN2=高 → 左电机反转
- 两个都低 → 停
- IN3/IN4 对右电机同理

## OUT1 / OUT2 / OUT3 / OUT4 接电机，不接 ESP

| L298N | 接到 |
|-------|------|
| OUT1 | 左电机的一根线 |
| OUT2 | 左电机的另一根线 |
| OUT3 | 右电机的一根线 |
| OUT4 | 右电机的另一根线 |

这四个螺丝是驱动器的**输出**，给桨供电。不要接到 NodeMCU。

以后网页点「前进」桨反了：只对调那一侧 OUT 的两根线。

你照片左上角三个螺丝是**电源**，右下角两个螺丝是**一侧电机输出**（OUT3/OUT4 或 OUT1/OUT2，看丝印）。

## 绿框 ↔ NodeMCU（和程序一致）

先拔掉 ENA、ENB 上的两个黑帽。

| L298N 绿框 | NodeMCU 丝印 | GPIO | 作用 |
|------------|--------------|------|------|
| ENA | **D5** | 14 | 左电机速度 PWM |
| IN1 | **D1** | 5 | 左电机方向 |
| IN2 | **D2** | 4 | 左电机方向 |
| IN3 | **D7** | 13 | 右电机方向 |
| IN4 | **D8** | 15 | 右电机方向 |
| ENB | **D6** | 12 | 右电机速度 PWM |
| GND（电源座中间那个，看丝印） | **GND** | — | 共地，必须接 |

**不要把 ENA、ENB 再接到 +5V。**  
ENA 只接 D5，ENB 只接 D6。接到 +5V 等于把两路 PWM 和 5V 短在一起，轻则不能调速，重则烧 ESP 引脚。

NodeMCU 上的 **3V3、A0、D3、D4 都不要接到 L298N**。
电池供电时：L298N 的 **+5V 只接到 NodeMCU 的 VIN（或 5V/VU）**，绝对不要接到 3V3。

## 电源（三个螺丝）— 电池同时给 L298N 和 ESP

电池 7.4V（2S）或 12V 都可以，螺丝叫 12V 不代表必须 12 伏。

**先拔掉电脑 USB。** 电池和 USB 不要同时给 ESP 供电。

三个螺丝旁那颗**小跳线帽保持戴着**（板载 5V 稳压）。ENA/ENB 那两颗帽子继续拔掉。

```
电池正极  ──→  L298N  +12V
电池负极  ──→  L298N  GND  ──→  NodeMCU  GND
                 L298N  +5V  ──→  NodeMCU  VIN（或标着 5V / VU 的脚）
```

| L298N 丝印 | 接到 |
|------------|------|
| +12V / VMS | 电池正极 |
| GND | 电池负极 **和** NodeMCU 的 GND |
| +5V | **NodeMCU 的 VIN**（不要接 3V3） |

NodeMCU 的 VIN 会再稳压成 3.3V 给芯片。接到 3V3 会灌 5V，可能烧板。

上电：先确认 GND 和信号线，再接电池。蓝灯闪、能搜到 wifi-boat 即成功。
稳压块会发烫，正常；太烫到烫手则先断电，改用单独 5V 给 ESP。

三个螺丝旁边/下方还有一颗**单独的小跳线帽**（板子上常常没有字），那是板载 5V 稳压开关。
**不要拔。** 以后接上 12V 电池时，L298N 自己靠它得到逻辑电。ENA/ENB 那两颗已经拔掉的帽子不要和它搞混。

第一轮测试：NodeMCU 继续用 USB 供电，L298N 用电池，**只共地**。
不要把电池 12V 接到 5V 螺丝，会烧板。

## 上电顺序

1. USB 拔掉
2. 信号线 + GND 接完，ENA/ENB 跳线帽已拔
3. 电机接到 OUT
4. NodeMCU 插回 USB
5. 电脑能看到 `wifi-boat` 热点后再接电池到 +12V 和 GND
6. 先点「停止」，再点「前进」看单侧桨

## 目前：只有一台电机，接在 OUT3 / OUT4

这是右通道。OUT1 / OUT2 空着没关系。

电池：

- 正极 → L298N **12V**（7.4V 或 12V 都可以，螺丝叫 12V 不代表必须 12 伏）
- 负极 → L298N **GND**（这个 GND 已经接到 ESP）
- **+5V 继续空着**
- 三个螺丝旁那颗小跳线帽保持戴着

网页测试（电机固定好，手不要碰桨）：

1. 先点 **停止**
2. 再点 **前进** → 电机应转
3. 点 **停止** → 应停
4. 点 **后退** → 应反转
5. 再点 **停止**

不转的话先看：电池有没有电、GND 是否共地、12V 有没有接到 5V 螺丝上。
