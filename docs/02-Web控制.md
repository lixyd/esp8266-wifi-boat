# 第二阶段：网页控制

目标：手机连上开发板热点，浏览器打开控制页，点按钮时电脑串口打印中文。
**不接 L298N，不转电机。**

## 手机怎么连

1. 烧录完成后，板载蓝灯仍大约每秒闪一次（表示程序活着）。
2. 打开手机 Wi-Fi，搜 **wifi-boat**
3. 密码：**12345678**
4. 连上后浏览器打开：**http://192.168.4.1/**
5. 有的手机会弹出「需要登录」页面，点进去就是控制页。
6. 点「前进」等按钮。

电脑上看结果：

- Arduino IDE：**Tools → Serial Monitor**，波特率 **115200**
- 或终端：

```bash
arduino-cli monitor -p /dev/cu.usbserial-10 -c baudrate=115200
```

每点一次按钮应出现：

```
[CMD] 前进  forward
```

## 热点打不开时

| 现象 | 处理 |
|------|------|
| 搜不到 wifi-boat | 确认蓝灯在闪；等 10 秒再搜；离板子近一点 |
| 能连上但网页打不开 | 关掉手机流量，地址必须是 `http://192.168.4.1/`（不是 https） |
| 串口没有 [CMD] | 网页是否提示发送失败；电脑串口波特率是否 115200 |
| 烧录失败占用串口 | 先关掉 IDE 的串口监视器再烧 |

改热点名字或密码：编辑 `firmware/wifi_boat/config.h` 里的 `WIFI_AP_SSID` / `WIFI_AP_PASSWORD`，重新烧录。密码至少 8 位。
