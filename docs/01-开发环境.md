# 第一阶段：开发环境

目标：电脑能识别开发板、能编译、能烧录 Blink。
本阶段 **不接 L298N、不接电机**。

## 1. 为什么先做环境

ESP8266 不是 Arduino Uno 那种官方板，Mac 默认不会：

1. 认出 USB 转串口芯片（本板是 CH340）
2. 知道怎么编译 ESP8266 的程序
3. 知道用什么波特率和复位时序去烧录

所以必须先装：Arduino IDE、ESP8266 板支持包。CH340 驱动视情况而定。

## 2. 确认 USB 已经连上

开发板用 USB-C 数据线插到 Mac。灯应该亮（红色电源灯常见）。

在「终端」执行：

```bash
ls /dev/cu.usbserial*
```

预期看到类似：

```
/dev/cu.usbserial-10
```

本机实测：

- 设备名：USB Serial
- 厂商 ID `0x1A86`，产品 ID `0x7523` → 沁恒 CH340
- 串口：`/dev/cu.usbserial-10`

### 失败怎么查

| 现象 | 原因 | 处理 |
|------|------|------|
| `/dev/cu.usbserial*` 一个都没有 | 线是纯充电线 | 换一根能传数据的 USB-C 线 |
| 板子灯全灭 | 没供电 | 换口、换线，确认 Mac 口能供电 |
| 只有 `cu.Bluetooth-Incoming-Port` | 系统没认出 CH340 | 拔掉再插；仍没有再考虑装 WCH 官方驱动 |
| 插上后出现 `cu.wchusbserial*` | 装过 WCH 驱动 | 也可以用，Arduino 里选这个口即可 |

**重要：** 本机已经出现 `cu.usbserial-10`，说明 macOS 自带驱动已经够用。
**不要再装** 网上的 CH340 kext。在 Apple Silicon + 新系统上，第三方驱动经常把已经能用的串口搞没。

## 3. 安装 Arduino IDE（图形界面）

给初学者点按钮、看串口监视器用。

Homebrew 安装：

```bash
brew install --cask arduino-ide
```

装好后在「启动台」或 `/Applications/Arduino IDE.app` 打开。

第一次打开如果弹出「来自身份不明的开发者」：

1. 系统设置 → 隐私与安全性
2. 拉到下面点「仍要打开」

预期：出现 Arduino IDE 主窗口，中间是空白编辑器。

### 失败怎么查

- `brew` 找不到：本机已有 Homebrew，一般不会
- 下载很慢：确认网络；Karing 开着也可以
- 打开后白屏：关掉重开一次，等它拉插件

## 4. 安装 arduino-cli（命令行）

和 IDE 共用同一套板支持包。我用它帮你编译烧录，你也可以继续用 IDE。

```bash
brew install arduino-cli
arduino-cli version
```

预期输出类似：`arduino-cli  Version: 1.x.x`

## 5. 安装 ESP8266 板支持包

### 5.1 命令行（推荐，一次到位）

```bash
arduino-cli config init
arduino-cli config add board_manager.additional_urls https://arduino.esp8266.com/stable/package_esp8266com_index.json
arduino-cli core update-index
arduino-cli core install esp8266:esp8266
```

这一步会下载编译器工具链，可能要几分钟。

预期最后出现：`Platform esp8266:esp8266@... installed`

验证：

```bash
arduino-cli board list
arduino-cli board listall nodemcu
```

`board list` 应能看到 `/dev/cu.usbserial-10`。
`board listall` 里应有 `NodeMCU 1.0 (ESP-12E Module)`，FQBN 为 `esp8266:esp8266:nodemcuv2`。

**为什么选 nodemcuv2：** NodeMCU V3 用的是 ESP-12E 模组，对应 Arduino 里的 “NodeMCU 1.0 (ESP-12E Module)”。不要选 “Generic ESP8266”，引脚编号会对不上。

### 5.2 如果你想自己在 IDE 里点

1. 打开 Arduino IDE
2. 左上角 **Arduino IDE** → **Settings…**（有的版本叫 Preferences）
3. 找到 **Additional boards manager URLs**
4. 填入：

   `https://arduino.esp8266.com/stable/package_esp8266com_index.json`

5. 点 OK
6. 左侧点 **开发板管理器**（棋盘图标），或菜单 **Tools → Board → Boards Manager**
7. 搜索 `esp8266`
8. 找到 **esp8266 by ESP8266 Community**，点 Install
9. 安装完后：

   **Tools → Board → ESP8266 Boards → NodeMCU 1.0 (ESP-12E Module)**

10. **Tools → Port → /dev/cu.usbserial-10**
11. **Tools → Upload Speed → 115200**（烧录不稳可改成 57600）

## 7. 编译并烧录 Blink

命令行：

```bash
cd ~/Desktop/esp8266-wifi-boat
chmod +x scripts/*.sh
./scripts/upload.sh
```

或手动：

```bash
arduino-cli compile --fqbn esp8266:esp8266:nodemcuv2 firmware/wifi_boat
arduino-cli upload --fqbn esp8266:esp8266:nodemcuv2 --port /dev/cu.usbserial-10 firmware/wifi_boat
```

### 在 Arduino IDE 里烧录

1. **File → Open…** 打开 `Desktop/esp8266-wifi-boat/firmware/wifi_boat/wifi_boat.ino`
2. 确认板型是 NodeMCU 1.0，端口是 `cu.usbserial-10`
3. 点右上角 **→**（Upload）
4. 底部黑色窗口会刷进度，最后应出现 `Hard resetting via RTS pin...`

### 预期现象

- 编译无红色报错
- 烧录时板子蓝灯可能闪一下（这是 ROM 引导，正常）
- 烧录结束后，**板载蓝灯约每秒闪一次**
- 串口监视器 115200 反复出现：

  ```
  Blink OK  LED ON
  Blink OK  LED OFF
  ```

看串口：

```bash
arduino-cli monitor -p /dev/cu.usbserial-10 -c baudrate=115200
```

IDE 里：菜单 **Tools → Serial Monitor**，右上角波特率选 **115200**。

## 8. 烧录失败排查

| 现象 | 处理 |
|------|------|
| `Permission denied` 打不开串口 | 关掉正在占用串口的监视器窗口，再烧一次 |
| `Failed to connect to ESP8266: Timed out` | 烧录开始瞬间按住板子上的 **FLASH** 键，看到开始写再松开 |
| 一直 `Connecting........_____` | 换数据线；Upload Speed 降到 57600；换 USB 口 |
| `can't open device '/dev/cu.usbserial-10'` | 拔掉再插，重新 `ls /dev/cu.usbserial*`，口名可能变了 |
| 编译报找不到 `ESP8266` | 板支持包没装好，重做第 5 步 |
| 烧录成功但灯不闪 | 有的板子蓝灯是 GPIO16，先看串口有没有 `Blink OK`。有字就说明 CPU 在跑 |
| 一烧录 Mac 弹出「网络」权限 | 可以允许；ESP 的 USB 转串口有时会被系统当成调制解调器 |
