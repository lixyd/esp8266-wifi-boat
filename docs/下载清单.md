# 第一阶段需要你手动下载的文件

本机访问 GitHub / arduino.cc 很慢，改由你在浏览器或下载器里下。
下完后把文件放到：

```
~/Desktop/esp8266-wifi-boat/downloads/
```

然后跟我说一声。

Mac 是 Apple Silicon，Arduino IDE 选 **macOS Apple Silicon (arm64)** 这一份。

---

## 必下（6 个）

### 1. Arduino IDE 2.3.10（图形界面）

- 文件名：`arduino-ide_2.3.10_macOS_arm64.dmg`
- 大约：160–180 MB（远小于 100 MB 就是没下完）
- 地址：

```
https://github.com/arduino/arduino-ide/releases/download/2.3.10/arduino-ide_2.3.10_macOS_arm64.dmg
```

发布页（找不到直链时打开这里，选 macOS Apple Silicon）：

```
https://github.com/arduino/arduino-ide/releases/tag/2.3.10
```

官网入口：

```
https://www.arduino.cc/en/software
```

### 2. ESP8266 板支持包 3.1.2

- 文件名：`esp8266-3.1.2.zip`
- 大小：39,269,515 字节（约 37.5 MB）

```
https://github.com/esp8266/Arduino/releases/download/3.1.2/esp8266-3.1.2.zip
```

### 3. 编译器 xtensa-lx106-elf-gcc（给 ESP8266 用）

- 文件名：`x86_64-apple-darwin14.xtensa-lx106-elf-e5f9fec.220621.tar.gz`
- 大小：75,923,095 字节（约 72.4 MB）
- 说明：名字带 x86_64 是正常的，Apple Silicon 会走 Rosetta，本机已经有 Rosetta。

```
https://github.com/earlephilhower/esp-quick-toolchain/releases/download/3.1.0-gcc10.3/x86_64-apple-darwin14.xtensa-lx106-elf-e5f9fec.220621.tar.gz
```

### 4. 便携 Python3（烧录脚本会用）

- 文件名：`python3-macosx-portable.tar.gz`
- 大小：25,494,144 字节（约 24.3 MB）

```
https://github.com/earlephilhower/esp-quick-toolchain/releases/download/2.5.0-4/python3-macosx-portable.tar.gz
```

### 5. mkspiffs

- 文件名：`x86_64-apple-darwin14.mkspiffs-7fefeac.220621.tar.gz`
- 大小：368,767 字节（约 360 KB）

```
https://github.com/earlephilhower/esp-quick-toolchain/releases/download/3.1.0-gcc10.3/x86_64-apple-darwin14.mkspiffs-7fefeac.220621.tar.gz
```

### 6. mklittlefs

- 文件名：`x86_64-apple-darwin14.mklittlefs-30b7fc1.220621.tar.gz`
- 大小：365,752 字节（约 357 KB）

```
https://github.com/earlephilhower/esp-quick-toolchain/releases/download/3.1.0-gcc10.3/x86_64-apple-darwin14.mklittlefs-30b7fc1.220621.tar.gz
```

## 建议也下（3 个，体积小，串口监视器用）

Arduino 官方 CDN 可能也很慢。能下就下；暂时下不到也可以先烧录，后面再补。

### 7. serial-discovery 1.5.2

```
https://github.com/arduino/serial-discovery/releases/download/v1.5.2/serial-discovery_v1.5.2_macOS_ARM64.tar.gz
```

### 8. serial-monitor 0.15.0

```
https://github.com/arduino/serial-monitor/releases/download/v0.15.0/serial-monitor_v0.15.0_macOS_ARM64.tar.gz
```

备用（官网 CDN，往往更慢）：

```
https://downloads.arduino.cc/discovery/serial-discovery/serial-discovery_v1.5.2_macOS_ARM64.tar.gz
https://downloads.arduino.cc/monitor/serial-monitor/serial-monitor_v0.15.0_macOS_ARM64.tar.gz
```

### 9. mdns-discovery 1.1.0（可选，自动发现板子用）

```
https://github.com/arduino/mdns-discovery/releases/download/1.1.0/mdns-discovery_v1.1.0_macOS_ARM64.tar.gz
```

## GitHub 直连失败时

把地址前面加上镜像前缀再试，例如：

```
https://ghfast.top/https://github.com/arduino/arduino-ide/releases/download/2.3.10/arduino-ide_2.3.10_macOS_arm64.dmg
```

其它文件同样：`https://ghfast.top/` + 原来的 GitHub 完整地址。

---

## 不用下

- **CH340 驱动**：板子已经被 macOS 认成 `/dev/cu.usbserial-10`（厂商 0x1A86，产品 0x7523）。再装第三方驱动容易把串口搞没。
- **L298N / 电机**：第一阶段不接。
