# 摄像头 / 麦克风（接不上 NodeMCU 给手机看）

实物：镜头外壳 **USB2.0 1.3Mega Pixel / Mobilechplus MW1350**。
圆板 **YC-08-A3** + 驻极体麦克风。线：红白绿黑。

这是 **USB 2.0 免驱摄像头（UVC，130 万像素）**，插头剪掉后露出 USB 四芯：

| 颜色 | USB |
|------|-----|
| 红 | +5V |
| 白 | D- |
| 绿 | D+ |
| 黑 | GND |

麦克风走 USB 音频。不是 OV2640，也不是给 ESP 引脚用的模拟头。

## 为什么不能接到 NodeMCU 上让手机看

ESP8266 **没有 USB 主机**。D+/D- 不能接到普通 GPIO。
把这四根线焊到 D1～D8 或 A0 不会出画面，还可能把板子搞坏。

语音识别按你的要求不做。这块麦也不是给 ESP 采样用的。

## 这四根线可以怎么用（不经过船）

焊回 USB 公头之后：

- 电脑：能当普通摄像头
- 部分安卓：OTG 可能认出 UVC
- iPhone：一般不认这种杂牌 UVC

船上要手机看画面，仍建议另买 **ESP32-CAM**。不要把 MW1350 焊到 NodeMCU。
