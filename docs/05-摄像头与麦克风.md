# 摄像头 / 麦克风（这块模组接不上 NodeMCU 给手机看）

实物：板子丝印 **YC-08-A3**，镜头 + 圆板上的模拟视频芯片 + 旁边那颗驻极体麦克风。
线：红 / 白 / 绿 / 黑，麦克风黄蓝。

这是 **模拟摄像头（CVBS 复合视频）**，给模拟显示器、录像机、5.8G 图传用的。
**不是** OV2640 / ESP32-CAM 那种数字摄像头。

## 为什么不能接到现在这块 NodeMCU 上让手机看

| 需要 | NodeMCU（ESP8266）实际 |
|------|------------------------|
| 把模拟视频采成数字画面 | 没有视频 ADC，A0 只能慢慢采电压，采不了电视信号 |
| 一帧图像的内存 | 大约 80KB RAM，连一张小图都勉强 |
| 网页视频流 | 这块板带电机网页已经很满，做不了实时画面 |

所以：**不是少写了代码，是芯片做不到。** 把视频线接到 D1～D8 或 A0 都不会出画面，还可能干扰电机控制。

麦克风：是模拟咪头，音频走在摄像头那路模拟线上。
手机语音识别、用这块板听声控，同样做不到。按你的要求：**语音识别不做。**

## 这四根线是给模拟设备用的（不要接到 ESP）

常见（以板子焊盘/丝印为准，上电前用表确认）：

| 颜色（常见） | 作用 |
|--------------|------|
| 红 | 电源，很多是 12V，有的 5–12V |
| 黑 | 地 |
| 白或绿 | 视频（接到显示器黄孔 / 图传 Video） |
| 剩下那根 | 常常是音频（这颗咪头） |

接到模拟显示器或 FPV 接收机才能看到图像。iPhone / 安卓 **没有** 这种模拟视频口。

## 想让手机看到船头画面，该换什么

买一块 **ESP32-CAM**（板载 OV2640）。它自己带 Wi-Fi，手机连它的热点就能看 MJPEG 画面。

和现在这艘船的关系：

- NodeMCU 继续管电机和遥控网页（现状不用推翻）
- ESP32-CAM 单独做「摄像头热点」，手机再连一次看画面  
  或者以后整船迁到 ESP32，电机和画面一块网页里

**不要把 YC-08-A3 焊到 NodeMCU 上。**
